# Extendeck – Privacy Policy

Extendeck does not collect, store or share any personal data.

Bluetooth is used exclusively to send MIDI messages to your computer. No data is sent to any server.

App settings are stored locally on your device only.

This website is hosted on GitHub Pages. GitHub may process technical data such as IP addresses when you visit it. See GitHub's privacy statement for details.
